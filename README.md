# Sanika Mane — Complete Mini Project Portfolio

This project contains all three required websites in one runnable folder:

1. Personal Portfolio — `index.html`
2. E-Commerce Website — `ecommerce.html`
3. College Website — `college.html`

## Folder structure

```text
Sanika-Mane-Complete-Portfolio/
├── index.html
├── ecommerce.html
├── college.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## Run all three

Open the folder in VS Code.

Install **Live Server — Ritwick Dey** if needed.

Right-click `index.html` → **Open with Live Server**.

Then use these links in the same browser/server:

- Portfolio: `index.html`
- E-Commerce: `ecommerce.html`
- College Website: `college.html`

The portfolio's Projects section already links to the E-Commerce and College pages, and both pages link back to the portfolio.

## GitHub

Create a repository named:

`sanika-mane-complete-portfolio`

Then in the VS Code terminal:

```bash
git init
git add .
git commit -m "Create complete Sanika Mane portfolio project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/sanika-mane-complete-portfolio.git
git push -u origin main
```

## GitHub Pages

GitHub repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Your live website will be:

`https://YOUR-USERNAME.github.io/sanika-mane-complete-portfolio/`

The three pages will be:

- `https://YOUR-USERNAME.github.io/sanika-mane-complete-portfolio/`
- `https://YOUR-USERNAME.github.io/sanika-mane-complete-portfolio/ecommerce.html`
- `https://YOUR-USERNAME.github.io/sanika-mane-complete-portfolio/college.html`

This is a front-end academic project; checkout and contact forms are demo interactions only.
